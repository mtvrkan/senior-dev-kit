# academic-write

Academic writing: argument-first structure, verified citations, intellectual honesty. See `agent_docs/academic-writing-guide.md` for document structures, citation formats, evidence calibration.

1. Clarify document type, audience, citation style, word count, existing sources — proceed without asking if clear. Build argument skeleton: thesis → evidence (3) → counterarguments → significance. Pause if thesis is weak.
2. Write section by section: topic sentence → evidence+citation → analysis → thesis connection.
3. Evidence language — strong (meta-analysis/consensus): "demonstrates"/"shows"/"confirms". Moderate (single study): "suggests"/"indicates". Weak: "may suggest". Never "research shows" without a citation, or "most agree" without consensus evidence.
4. Self-review: every claim cited, no [UNVERIFIED] placeholders, no fabricated stats or quotes.
