# Academic Writing Guide

Reference for `/academic-write` skill — document structures, citation formats, and evidence calibration.

---

## Document structures

### Research paper / article

```text
Abstract (150-250w): purpose + method + key finding + significance
Introduction: hook → gap → thesis → roadmap
Literature Review: organized by theme, not chronology
Methodology: replicable, justified, limitations stated
Results: what was found (not interpreted)
Discussion: interpretation, implications, limitations
Conclusion: restate thesis differently + future research
References: per target style
```

### Literature review (standalone)

```text
Introduction: scope + method + why this review is needed
Themes (3-7): claim → what literature says → gaps → your synthesis
Synthesis: patterns across themes
Research gaps: specific + actionable
Conclusion: state of knowledge + implications
```

### Thesis chapter

Follow thesis supervisor's format. Default:

```text
Chapter intro → literature (chapter-specific) → methodology → findings → discussion → chapter summary
```

### Research proposal

```text
Problem statement: gap in knowledge + why it matters
Research questions: 2-4 specific, answerable questions
Literature review: what's known, what's missing
Methodology: design + sampling + data collection + analysis plan
Timeline: realistic milestones
Expected contribution: what this adds
Budget: if required
References
```

### Conference abstract

```text
Background / motivation (1-2 sentences)
Method (2-3 sentences)
Results / findings (2-3 sentences)
Conclusion / significance (1-2 sentences)
Keywords: 4-6 terms
```

## Citation format by style

**APA 7:**

- In-text: `(Author, Year, p. X)` or `Author (Year) found...`
- Reference: `Author, A. A. (Year). Title. Publisher. https://doi.org/x`

**MLA 9:**

- In-text: `(Author page)` or `Author argues...`
- Works Cited: `Author. "Title." *Journal*, vol. N, no. N, Year, pp. X-X.`

**Chicago Notes (17th):**

- Footnote: `¹ Author, *Title* (Publisher, Year), page.`
- Bibliography: `Author. *Title*. Publisher, Year.`

**IEEE:**

- In-text: `[1]` in order of first appearance
- Reference: `[1] A. Author, "Title," *Journal*, vol. N, no. N, pp. X-X, Year.`

**Vancouver:**

- In-text: `(1)` or superscript
- Reference: `1. Author A, Author B. Title. Journal. Year;vol(issue):pages.`

## Evidence language calibration

| Evidence strength | Language to use |
| --- | --- |
| Meta-analysis / RCT / established consensus | "demonstrates" · "shows" · "found" · "confirms" · "establishes" |
| Single study / moderate evidence | "suggests" · "indicates" · "found evidence that" · "reported" |
| Preliminary / weak evidence | "may suggest" · "preliminary evidence indicates" · "one study found" |
| Unknown / insufficient evidence | "it is unclear" · "evidence is mixed" · "has not been studied" |

**Never:**

- "Research shows" without a specific citation
- "Most researchers agree" without evidence of consensus
- Statistics presented without source
- Quotes without page numbers (if style requires)

## Argument skeleton template

```text
ARGUMENT SKELETON: [title]
========================
Thesis: [one sentence — specific, contestable claim]

Evidence supporting thesis:
1. [source/finding — type of evidence — strength]
2. [source/finding — type of evidence — strength]
3. [source/finding — type of evidence — strength]

Primary counterarguments:
A. [counterargument] — how it will be addressed: [rebuttal approach]
B. [counterargument] — how it will be addressed: [rebuttal approach]

So what (significance):
[Why this matters — practical / theoretical / policy implications]
```

Pause here if the thesis is unclear or evidence is insufficient. Do not write paragraphs over a weak foundation.

## Self-review checklist

- [ ] Every major claim has a citation
- [ ] No [UNVERIFIED] placeholders remain
- [ ] Abstract contains all 4 elements (purpose / method / findings / significance)
- [ ] Counterarguments addressed honestly
- [ ] Conclusions don't exceed what evidence supports
- [ ] Citation format consistent throughout
- [ ] No fabricated statistics or quotes
- [ ] Word count within specified limit
