# /smart-task

Classify and route the task before coding.

Task: $ARGUMENTS

Output:
TASK TYPE: [bug-fix | feature-build | feature-plan | code-review | test-writer | db-change | migration-review | data-modeling | security-review | security-scan | performance-check | refactor-safe | docs-update | release-check | ui-change]
STACK DETECTED: [framework / language / ORM / DB]
RISK: low | medium | high | critical
SUBAGENT NEEDED: yes ([which agent]) | no
SKILL: [which skill]
PLAN:

  1. [step]
  2. ...
VERIFY WITH: [commands if they exist in this project]

Do not edit files unless the user explicitly asks to proceed after seeing this plan.
