# /agents-guide

Read `agents/ROUTING.md` under KIT ROOT (the kit's single routing source of truth — KIT ROOT is
`~/.claude/` for a copy install, the plugin directory for a plugin install) and summarize for the
user: each installed agent, its model tier, and when to use it — plus the escalation chain and the
guard agents that protected-area work must route through.

Keep the summary to one table (agent | model | when to use) and 3-4 lines of escalation notes.
Do not restate the full decision tree — link the user to ROUTING.md for detail.
