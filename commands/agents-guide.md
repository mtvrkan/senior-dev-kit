# /agents-guide

Read `~/.claude/agents/ROUTING.md` (the kit's single routing source of truth) and summarize
for the user: each installed agent, its model tier, and when to use it — plus the escalation
chain and the guard agents that protected-area work must route through. If ROUTING.md is
missing at that path, read `agents/ROUTING.md` from the kit repo instead.

Keep the summary to one table (agent | model | when to use) and 3-4 lines of escalation notes.
Do not restate the full decision tree — link the user to ROUTING.md for detail.
