# /strategy-plan

Produce a strategic plan or decision analysis for: $ARGUMENTS

Process:

1. Frame the decision or problem in one sentence.
2. Map current state, constraints, and goals.
3. Generate at least 2 meaningfully different options.
4. Analyze trade-offs per option.
5. Recommend one with clear rationale.
6. Surface assumptions that would change the recommendation.

Output:
PROBLEM / DECISION: [one sentence]
CONTEXT: [constraints, goals, timeline]
OPTIONS:
  A. [name] — pros / cons / risk
  B. [name] — pros / cons / risk
RECOMMENDATION: [option + rationale]
ASSUMPTIONS: [list]
NEXT STEP: [one concrete action]
OPEN QUESTIONS: [what would change the recommendation]

Do not edit code files.
Always present at least 2 options.
